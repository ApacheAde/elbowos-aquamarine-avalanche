# Aquamarine Avalanche

Full-colour Python 3 neon gem-catch arcade for ElbowOS.

Catch falling aquamarine / cyan gems with the paddle for points and combos.  
Avoid magenta mines that deduct score.  

Controls: A / D or ← → move the paddle. ESC to quit.

## Play

```bash
pip install -r requirements.txt
python3 aquamarine_avalanche.py
```

## Record 9:16 reel (headless)

```bash
python3 aquamarine_avalanche.py --record
```

Outputs AquamarineAvalanche_ElbowOS.mp4
